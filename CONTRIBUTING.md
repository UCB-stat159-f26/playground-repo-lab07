# Contributing Checklist

Work through these on **your fork**, in your own clone. Each one is small —
this is about practicing the fork → edit → commit → push loop, not about
writing a lot of new content.

- [ ] **Fix the typo.** Somewhere in `README.md` there's a misspelled word.
      Find it and fix it.
- [ ] **Fix the broken link.** The README links to `CONTRIBUTING.md` but gets
      the filename wrong, so the link doesn't work. Fix the link so it points
      to the right file.
- [ ] **Add a "Getting Started" section.** The README is missing one. Add a
      `## Getting Started` section near the top (right after the intro
      paragraph is a good spot) with at least these two bullets:
  - [ ] How to install the dependencies (hint: what would someone need to run
        `analysis.py` or `analysis.R`?)
  - [ ] How to run the analysis script

When you're done, commit your changes with a clear message and push them to
**your fork**.
